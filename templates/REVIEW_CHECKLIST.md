# Pull request review checklist

- [ ] **Correctness** — does it do what the issue says? edge cases (empty, zero, boundary)?
- [ ] **Readability** — clear names, small functions, comments where needed
- [ ] **Tests** — do tests cover the change, including one boundary case?
- [ ] **Security** — no secrets, no personal data, inputs validated, nothing sensitive logged
- [ ] **Maintainability** — simplest design that works; no unnecessary abstractions
- [ ] **AI-generated code** — packages exist? tests not weakened? author can explain it?

Label your comments: **Blocking:** / **Question:** / **Suggestion:** / **Nit:** / **Praise:**
