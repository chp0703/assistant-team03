# Documentation Overview

Welcome to the documentation directory of the **Smart Virtual Assistant** project (`assistant-teamNN`). This section outlines the structural architecture, team organization, and component responsibilities.

## Directory Structure & Responsibilities

The project is cooperatively maintained by a 4-member team, structured as follows:

- **`README.md` & Root Configuration** (`.gitignore`, `requirements.txt`, `pyproject.toml`) — Managed by **Member 1**
- **Backend & Environment Script** (`src/assistant/`, `scripts/check_env.py`) — Managed by **Member 2**
- **UI Plan & Data Sources** (`ui/README.md`, `data/README.md`) — Managed by **Member 3**
- **Tests & Documentation** (`tests/`, `docs/README.md`, `docs/team.md`) — Managed by **Member 4** (Current section)
